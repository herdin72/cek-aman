Report a contract / Laporkan kontrak

You need an Agent ID. You send the transaction yourself, from your own Agentic Wallet, and confirm it there. This page never connects to a wallet and never asks for a key, seed phrase, pairing code or QR login.

Butuh Agent ID. Transaksi kamu kirim sendiri dari Agentic Wallet kamu dan kamu konfirmasi di sana. Halaman ini tidak pernah minta kunci, seed phrase, kode pairing, atau login QR.

Only paste a prompt you made yourself on this page. Always read the preview before confirming: it must show value 0, no approval, and the Cek Aman contract address above.

First report = free soulbound Guardian badge (gas only, about 250k gas). You can change or withdraw your report any time.

How it works

  1. One Agent ID, one voice. Only addresses holding an Agent ID can report, one report per contract. Agent IDs are soulbound and one per address, so fake accounts can't pile on.
  2. Proof of claim. When you report, Cek Aman asks the target for your balance. If you really hold its token or NFT, your report is marked proof-backed.
  3. Contracts only. You can only report contracts, never personal wallets.
  4. Safe by design. No owner, no admin, no upgrades, no payable functions, no approvals, no token transfers. Open source and verified.
  5. Not financial advice. Reports are opinions of community members. Always do your own research.
